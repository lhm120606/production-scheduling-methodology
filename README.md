# Production Scheduling Methodology

An interactive showcase of a planning workflow for production operations. It walks through defining delivery goals, working backward through task dependencies, accounting for resource constraints, and updating the plan from progress feedback.

## Stack and features

- HTML, CSS, and vanilla JavaScript.
- Four interactive planning stages with keyboard navigation.
- A static, Chinese-language interface with no backend or installation dependencies.

## Run locally

From the repository root, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000` and select each planning stage to explore its details.

## Portfolio contribution

The portfolio work focuses on presenting a production-planning workflow through a standalone interactive explanation. This repository documents the methodology and its presentation.
